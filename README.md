🎓 ExamNexus – Smart Online Examination Platform
ExamNexus is an online examination platform designed to make assessments more organized, secure, and efficient for teachers and students.
🚀 Key Features
👨‍🏫 Teacher Space
- Create and manage examinations.
- Add 1-mark MCQ questions.
- Create 4-mark and 12-mark descriptive questions.
- Evaluate descriptive answers.
- Publish examination results.
👨‍🎓 Student Space
- Access available examinations.
- Attend online assessments.
- Submit answers through the platform.
🛡️ Cheat Detection System
- Monitors suspicious examination activities.
- Tracks word count and typing behaviour.
- Detects screen switching during examinations.
- Records suspicious activities for teacher review.
📊 Exam Results
- Displays examination results.
- Helps teachers review student performance.
- Provides a structured assessment workflow.
